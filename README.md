### Principais recursos
- **Modos Leitura e Edição** com sincronização automática da linha editada.
- **Múltiplas abas na mesma instância** com suporte a duplo-clique no Explorador de Arquivos.
- **GitHub Flavored Markdown (GFM)**, syntax highlighting com botão **Copy** e diagramas **Mermaid**.
- **Temas Light, Dark, Dracula e System**, largura de leitura ajustável e zoom com `Ctrl + Scroll`.
- **Busca rápida (`Ctrl + F`)** e lista de **Arquivos Recentes**.

> **Nota sobre o Windows SmartScreen:** por ser um projeto gratuito e independente sem certificado pago, o Windows pode exibir *"O Windows protegeu o computador"*. Clique em **Mais informações** → **Executar assim mesmo**.
